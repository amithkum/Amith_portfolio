# Amith Kumar R — Professional Portfolio

A responsive portfolio built with plain HTML, CSS and JavaScript. No npm, React or build step is required.

## Run in VS Code
1. Extract the ZIP.
2. Open the `amith-portfolio` folder in VS Code.
3. Open `index.html` in a browser, or install the **Live Server** extension and choose **Open with Live Server**.
4. Keep `assets/profile.png` in the same folder structure so the profile photo loads.

## Main files
- `index.html` — portfolio content and sections
- `style.css` — design, responsive layout and animations
- `script.js` — scroll reveal and mobile navigation
- `assets/profile.png` — supplied professional photo
